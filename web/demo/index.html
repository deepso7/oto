Oto-1 in an AudioWorklet

Pure-Rust Oto-1 kernel compiled to wasm32-unknown-unknown (no wasm-bindgen, zero imports), run one 512-sample hop per four 128-sample render quanta inside the worklet. Random weights unless you pick a .otow file. Chain delay 1024 samples (21.33 ms) plus the browser's own context and device latency.
